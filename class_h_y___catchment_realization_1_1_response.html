Detailed Description

The response value distilled by this perspective, in every way the perspective can express it.

A formulation typically answers in a depth, because that is what realization::Formulation::get_response asks its model for. What a depth means for the feature is the perspective's to say, so each subtype expresses it in the terms its own topology implies – a face has an extent to spread it over, an edge does not.

A perspective offers what it can express of the step so a caller that is handed something it cannot read finds out by asking.
