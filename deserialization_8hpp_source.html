18Interface of the BMI state restore protocol. Pairs with
19`NgenSerializationProtocol` (save); shares the `Record` value type
20defined in `include/utilities/serialization/record.hpp`.
21
22Storage is delegated to a `RecordBackend` acquired at `initialize()`
23time, optionally scoped by a caller-provided `id_subset` so that a
24run restoring only a known subset of features can give the backend
25a chance to build a smaller index.
26
27Each `run()` opens a short-lived `Reader` for the current
28`ctx.id` and asks the configured match mode (`latest`, by step, or
29by timestamp) for the corresponding record.
30*/
