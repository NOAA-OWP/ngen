std::optional< double > hy_features::attributes::area_from_geometry ( const geojson::geometry & geometry)
inline

The area a feature's geometry encloses, in square kilometers, where it encloses one.

Read through the feature rather than copied out of it: a divide is large, and nothing measuring one needs to own it.

A non-positive result means the polygon is degenerate or wound the wrong way, which is no more an extent than no polygon at all.

References geometry.

double hy_features::attributes::area_sqkm ( const geojson::Feature & feature,
AreaSource preferred = AreaSource::attribute )
inline

The areal extent of a catchment feature, in square kilometers.

A hydrofabric gives this twice over: as an attribute, and as the divide whose area can be measured. Either answers, so preferred decides only which is consulted first and the other still serves when it is absent. Nothing guarantees they are equal, so which one to use is a choice.

Parameters
featureThe hydrofabric feature a catchment is realized from.
preferredWhich source to consult first. Defaults to attribute.
Exceptions
std::invalid_argumentIf the feature carries neither an area attribute nor a divide.
