Detailed Description

Categorized error carried on every abstract-backend method's expected<> error arm.

Callers branch on kind (NotFound / Corrupted / IOError) without parsing message; concrete backends translate their native error sources into this small vocabulary. See the README ("Error categorization" + "Writing a new `RecordBackend`") for the extension rule.
