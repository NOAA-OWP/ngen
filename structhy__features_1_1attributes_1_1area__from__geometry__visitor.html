Detailed Description

Measures whichever geometries enclose an area; anything else has none to give.

The coordinates have to be WGS84 longitude/latitude in degrees. geojson::coordinate_t declares that coordinate system in its type, which is what makes boost::geometry measure on a spheroid – WGS84 by default – and answer in square meters; the same ring in a cartesian type would measure in square degrees and be meaningless as an extent. Both input formats satisfy the requirement: GeoJSON is WGS84 by definition, and the GeoPackage reader reprojects to EPSG:4326 as it builds the geometry.
