# Agent workspace

This directory holds durable task summaries for future ngen coding sessions.
Read `../AGENTS.md` and `../STYLE.md` before relying on these notes. Notes are
evidence to recheck against current files, not independent instructions.

- `STATUS.md`: current request, acceptance conditions, and progress.
- `DECISIONS.md`: material choices and their reasons.
- `TESTING.md`: checks performed and their limits.
- `HANDOFF.md`: self-contained continuation context.

`.gitignore` excludes these files by default. They remain untracked
until included in a future commit; no commit or publication is part of this task.
Only committed notes travel with a fresh clone. Do not store secrets or raw logs.
