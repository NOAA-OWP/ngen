Detailed Description

The two-dimensional realization of a catchment: the face it covers.

Topologically a face bounded by catchment divide and flowpath edges, so this is the perspective to ask for an areal extent – the denominator when a value is distributed over the catchment.

Realize a catchment from the hydrofabric feature describing it.

A convenience over the constructor above for the common case, taking the feature apart so a caller does not have to: the extent comes from hy_features::attributes::area_sqkm, the face from the feature's own geometry. What is kept is the same either way – an extent and a geometry, never the feature.

std::optional< double > HY_CatchmentArea::area_sqkm ( ) const
inlineoverridevirtual

The areal extent of this feature, in square kilometers, where the perspective has one.

A face has an area, and so does the edge bounding that face; the edge running through it has a length instead. Empty therefore says the perspective has no extent to give, never that the hydrofabric withheld one: a catchment whose hydrofabric carries no extent is refused when the realization is built, so it does not reach here.

◆ get_bounds()

const std::shared_ptr< const geojson::geometry > & HY_CatchmentArea::get_bounds ( ) const
inline

The geometry describing this face, empty where no hydrofabric feature backs it.

Shared with the feature it was read from rather than copied out of it: a divide runs to thousands of coordinates, and holding one per realization would duplicate what the fabric already has. A handle rather than a reference, so a consumer that outlives this realization – a domain layer resampling onto the catchment – can keep the divide after both this and the feature collection are gone.

The variant, not a polygon: a feature may describe its face as either a Polygon or a MultiPolygon, and narrowing to one of them is what would force a copy of the other.

Build the catchment this feature is a perspective of, and bind the two together.

The catchment is given this realization's identity, so the pair cannot disagree about what it names. Each then holds the other: the catchment owns its realization, and the realization reaches back to the catchment for its nexuses.

One realization is one perspective of one catchment. Calling this again returns the catchment already built and does not apply the arguments; realizing a catchment from another perspective means another realization, which builds its own.

Parameters
inflowsIds of the nexuses contributing to the catchment.
outflowsIds of the nexuses the catchment contributes to.
layerThe hydrofabric layer the catchment belongs to.
Returns
The catchment, newly built or the one this realization already built.
Exceptions
std::bad_weak_ptrIf this realization is not already held by a shared_ptr.
