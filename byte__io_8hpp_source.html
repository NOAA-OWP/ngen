17INTERNAL — implementation detail of wire_format::RecordPrefix.
18
19Names the byte-level primitives `wire_format` uses, in one place:
20
21 * Buffer-level: `store_little_uXX` / `load_little_uXX` (and the
22 signed `sXX` counterparts) act on `uint8_t*` buffers and compute
23 values arithmetically from byte sequences.
24 This ensures the wire-format's cross-host portability: same bytes on disk from any
25 host, correct numeric values when read on any host.
26
27 * `store_little_u8` / `load_little_u8` are single-byte trivials defined here.
28 These are just for consistency.
29
30 * Stream adapters (`write_uXX_le(ostream, v)`,
31 `read_uXX_le(istream, v_out)`) wrap the buffer primitives for
32 callers that work with `std::ostream` / `std::istream`.
33 These encapsulate the stack-buffer-then-cast-then-write pattern
34 so the `reinterpret_cast<char*>(uint8_t*)` bridge between the
35 primitives' byte type and the iostream `char*` API is in one
36 place.
37
38Signed-integer encoding inherits boost::endian's two's-complement
39assumption ([1], [2]). C++20 mandates two's-complement, so the
40run-host canary tests in byte_io_Test.cpp are formalities on any
41conforming toolchain — kept as a safeguard against nonconforming
42toolchains and possible ports to older standards.
43
44 [1] versioned (matches the Boost we link against):
45 https://www.boost.org/doc/libs/1_86_0/libs/endian/doc/html/endian.html
46 [2] latest release (in case the versioned page diverges):
47 https://www.boost.org/doc/libs/release/libs/endian/doc/html/endian.html
48
49Visibility is enforced by include-path discipline: this header is
50only on the PRIVATE include path of the `ngen_bmi_protocols` library's
51own translation units and of the `test_bmi_protocols` test target. It
52is never exported via `target_include_directories(PUBLIC ...)`.
53*/

69// Compile-time guard for the `reinterpret_cast<char*>(uint8_t*)`
70// bridge in the stream adapters below. The standard does not
71// mandate that `std::uint8_t` alias `unsigned char` — it only
72// requires that the type exist, be unsigned, and be exactly 8
73// bits. In most scenarios the two are aliases, and the
74// reinterpret_cast is well-defined via the standard's
75// `char`/`unsigned char` aliasing rules. The assertion below
76// catches any future target where the alias does not hold.
77static_assert(
78 std::is_same<std::uint8_t, unsigned char>::value,
79 "byte_io: std::uint8_t must alias unsigned char on this "
80 "target — the stream adapters' reinterpret_cast<char*> "
81 "bridge depends on it. See the comment immediately above "
82 "this assertion for the rationale."
83);

101// Added for consistency, these are essentially noops
102inline void store_little_u8(uint8_t* p, uint8_t v) {
103 p[0] = v;
104}
105
106inline uint8_t load_little_u8(const uint8_t* p) {
107 return p[0];
108}

110// ============================================================
111// Stream adapters — wrap the buffer primitives for callers that
112// work with iostream rather than raw byte buffers.
113//
114// Each adapter contains the `reinterpret_cast<char*>(uint8_t*)`
115// that bridges the buffer primitives' byte type to the iostream
116// API. The cast is guarded by the static_assert at the top of
117// this header.
118// ============================================================
119
120inline void write_u8(std::ostream& out, uint8_t v) {
121 uint8_t buf[1];
122 store_little_u8(buf, v);
123 out.write(reinterpret_cast<const char*>(buf), 1);
124}
125
126inline bool read_u8(std::istream& in, uint8_t& v) {
127 uint8_t buf[1];
128 if (!in.read(reinterpret_cast<char*>(buf), 1)) return false;
129 if (in.gcount() != 1) return false;
130 v = load_little_u8(buf);
131 return true;
132}
