Detailed Description

A writer for one checkpoint event.

Obtained only via RecordBackend::writer(); cannot be constructed standalone or mixed across backends.

virtual auto ngen::serialization::RecordBackend::Writer::commit ( ) -> expected< void, BackendError >
nodiscardpure virtual

Commit the event: flush pending writes, make them durable (under Durability::strict), surface deferred errors, run any collective barriers the backend requires.

With Durability::relaxed, durability is best-effort and errors may not surface until the parent backend's finalize() call.

virtual auto ngen::serialization::RecordBackend::Writer::write ( const RecordView & rv) -> expected< void, BackendError >
nodiscardpure virtual

Append a record to this checkpoint event.

The caller owns the RecordView's payload bytes for the duration of this call; the writer streams them to storage and does not retain the pointer after returning. Error arm carries a backend-specific diagnostic if the append fails (I/O error, oversized payload, etc.).
