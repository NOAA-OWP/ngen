Detailed Description

Reading the hydrofabric attributes a catchment is realized from.

GeoPackage is the current input format and GeoJSON remains supported. Both are read into the same geojson::Feature, in WGS84 either way, so these cases stand for both; what differs between them is how an attribute is spelled, which is the subject of the first cases here.
