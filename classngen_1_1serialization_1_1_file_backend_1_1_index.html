static auto ngen::serialization::FileBackend::Index::build ( const std::string & path,
const IdPredicate & index_scope ) -> expected<std::shared_ptr<const Index>, BackendError>
inlinestatic

Walk path and build an index of records whose id satisfies index_scope.

An empty predicate means "index everything." Returns a non-null shared_ptr<const Index> on success; the IOError arm fires only on stream-open failure of a kind that isn't "file doesn't exist" (missing-file yields an empty index — a valid outcome that pairs with NotFound on every Reader lookup).
